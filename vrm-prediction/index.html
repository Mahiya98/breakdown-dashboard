Ranking is over the 3 breakdown categories this project predicts (electrical, mechanical, any-eligible) — "any" is the union of the two and is included because it was the originally validated target; it is not an independent 4th category. Detailed-reason-level ranking (the finer-grained "top 3 specific reasons") is not available yet — see step10_reason_modeling_plan.md, which documents that this requires a data audit and model training that has not been completed.

The reason column is the real logged reason/grouping for that target date (e.g. "Bag House / Bag Filter / Dust Collection — LRS Problem"), shown whenever a breakdown actually occurred — it is ground truth, not a model prediction. It is blank when no breakdown was logged that day, or when known reasons that day don't belong to this row's category. Up to the top 3 reasons for that day are shown, ranked by logged downtime minutes. A dedicated model that predicts the likely reason in advance has not been built yet (see step10_reason_modeling_plan.md).
